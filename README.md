## Overview
MiniMart is a small **ASP.NET Core MVC** web app created for the IS4439 CA1 project.  
It demonstrates the key concepts of MVC: routing, models, validation, layouts, and tag helpers.  
The app is styled with **Pico.css** for a clean UI.

---

## Features
- Custom layout with Pico.css and a blue navigation bar.  
- Product list page displaying sample products.  
- Product details page using an **attribute route**.  
- Add Product form with **model validation** (`[Required]`, `[Range]`, `[StringLength]`).  
- Custom 404 error page using the same layout.  
- Custom `<test>` tag helper that renders as a link to UCC.  
- About page explaining what the app does.

---

## How to Use
- **Home:** Introduction and navigation.  
- **Shop → List:** View all products.  
- **Shop → Details:** View info about a single product.  
- **Shop → Add:** Add a new product (form with validation).  
- **About:** Learn about MiniMart.  
- Invalid pages show a custom 404 message.
